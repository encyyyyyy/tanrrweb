Tanrr Social Publishing Review

This page documents the private Tanrr scheduler used to publish Tanrr-owned content to TikTok and Instagram. The scheduler dashboard runs locally on the owner's Mac and is not exposed publicly.

Overview

Tanrr uses a private local scheduler to prepare captions, videos, and image carousels for six Tanrr-managed social accounts. The app replaces a third-party scheduling service and does not provide public user registration, public posting, or third-party account management.

App owner

Nicholas Conoplia owns and operates Tanrr independently.

Purpose

Schedule and publish Tanrr marketing content to owner-authorized TikTok and Instagram accounts.

Public access

No public dashboard is available. The scheduler UI runs on localhost for the owner only.

Data handling

OAuth tokens are stored locally in encrypted JSON on the owner's Mac.

TikTok Flow

The TikTok integration uses the Content Posting API upload-to-inbox workflow, not Direct Post. The owner authorizes each TikTok account, the scheduler uploads the video or photo slideshow, and TikTok sends an inbox notification for final review and posting inside TikTok.

  • Requested scopes: user profile display access and video.upload.
  • Video posts use inbox upload with file upload from the local scheduler.
  • Photo slideshows use media upload with verified Tanrr media URLs after domain verification is approved.
  • Captions are stored in the local scheduler for copy/paste during manual TikTok review when needed.

Instagram Flow

The Instagram integration uses the Instagram Graph API for professional accounts connected to Facebook Pages. Videos publish as Reels by default. Multi-image posts publish as carousel media containers after the scheduler checks container readiness.

  • Requested permissions include instagram_basic and instagram_content_publish.
  • All Instagram accounts are Tanrr-owned or Tanrr-managed professional accounts.
  • Captions are submitted through the Instagram publishing container flow.
  • No public user content is collected through this website.

URLs

These are the intended public URLs for platform configuration after the tunnel or domain rewrite is active.

TikTok OAuth callback

https://publish.gettanrr.com/api/social/oauth/tiktok/callback

Instagram OAuth callback

https://publish.gettanrr.com/api/social/oauth/instagram/callback

Public media URL pattern

https://publish.gettanrr.com/api/social/public-media/[private-media-token]/[generated-file]

Access And Security

  • The scheduler dashboard is localhost-only and is not linked from this website.
  • The public API listener exposes only OAuth callbacks and tokenized media files.
  • Media filenames are generated randomly and retained temporarily for publishing workflows.
  • OAuth state is random, single-use, and expires after a short window.
  • This review page is intentionally unlisted and noindexed. It does not contain OAuth secrets, account tokens, or private account credentials.
